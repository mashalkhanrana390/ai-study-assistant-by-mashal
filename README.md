# 📚 AI Study Assistant

AI Study Assistant is a study management project made with python by Mashal Khan

This project will be used as a study helper for students and will slowly grow to have many more features like subjects, notes, quizzes and progress.

## 🚀 Features

- Add a subject
- Simple menu system
- User input
- Subject information display
- Menu selection with use of conditionals

## 🛠️ Technologies

- Python 3
- Python Functions
- Variables
- `input()`
- `print()`
- `if` statements
